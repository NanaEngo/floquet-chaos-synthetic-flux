# floquet-chaos-synthetic-flux

Public deposit for *Synthetic-flux control of hyperchaos order in a
dissipative optomechanical model* (Communications in Nonlinear Science and
Numerical Simulations).

Does a gauge-invariant synthetic-flux phase control the *order* of a
drive- and coupling-gated hyperchaos transition in a six-dimensional
dissipative optomechanical model? Yes at the model level: the full
six-exponent Lyapunov spectrum resolves up to four simultaneously positive
directions, the onset is localized to a Neimark--Sacker bifurcation, and a
matched-resource force-sensing protocol returns null gain on the chaotic
attractor.
