# Figures directory

Figures must be generated from immutable files in `../results/` by versioned scripts in `../scripts/`.

Every figure requires:

- source-data ID;
- generator script and git revision;
- unit/time-convention declaration;
- vector output where possible;
- final-size visual inspection;
- a text scan confirming that `P4`, `P5`, `mock`, `placeholder`, and `representative` do not appear in publication labels.
